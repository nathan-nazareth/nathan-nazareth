# Nathan Nazareth

**Games, tools and the plumbing in between.**

I build things that run in a browser: game engines with a spine of canon behind
them, small business tools that have to be right rather than impressive, and the
deploys and data layers that keep them honest.

**[Portfolio →](https://portfolio.n8-nazareth.workers.dev)**

## How I work

- **Cloudflare** for the edge — Workers for the apps, static assets for the pages.
- **TypeScript** everywhere, and a hard rule that a package's public surface is
  its entry points and nothing else.
- **GitHub** for the source, the issues and the automation.
